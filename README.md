# Дневник

Расписание уроков и домашнее задание для класса. Работает как обычный сайт (PWA) и как
Android-приложение (APK). Без интернета показывает последнюю сохранённую версию.

- Приложение (PWA): https://hokch1k.github.io/dnevnik/
- APK для Android: https://hokch1k.github.io/dnevnik/Dnevnik.apk

## Как поставить одноклассникам

- **Телефон Android:** открыть ссылку на APK, скачать, установить (разрешить установку из
  неизвестного источника, если система спросит). После установки интернет нужен только для
  обновления домашки.
- **iPhone / без установки:** открыть ссылку приложения в браузере и добавить на главный
  экран («Поделиться» → «На экран "Домой"»). Дальше работает как обычное приложение, в том
  числе без интернета.

## Что где

| Файл | Назначение |
|------|------------|
| `data.json` | **Единственное место, где лежит домашка.** Отсюда данные берёт приложение |
| `index.html` | Сам интерфейс. Внутри — встроенная копия `data.json` (чтобы работало с первого запуска без сети) |
| `sw.js` | Service worker: кэш для офлайна |
| `tools/gen-seed.js` | Переносит `data.json` внутрь `index.html` |
| `tools/check.js` | Проверка вёрстки и офлайн-режима в headless Chrome |
| `android/` | Исходники Android-приложения (WebView + локальный сервер ассетов) |
| `Dnevnik.apk` | Готовый APK для установки на телефон |

## Как обновляется домашнее задание

1. Правим `data.json` (даты, уроки, `hw`).
2. `node tools/gen-seed.js` — встроенная копия в `index.html` обновляется.
3. Коммитим и пушим в `main`.

Приложение при каждом открытии (и каждые 90 секунд, пока открыто) скачивает `data.json`
с GitHub и сохраняет его в память телефона. Если сети нет — показывает сохранённую копию и
красную плашку «Нет интернета · последнее обновление: …».

## Обновление самого приложения

- Браузерная версия обновляется сама: service worker отдаёт свежие файлы с GitHub.
- APK проверяет `version.json` (поле `code`). Если в нём число больше, чем в приложении,
  появляется подсказка, а в «i» — кнопка «Обновить приложение», которая качает свежий
  `Dnevnik.apk` с GitHub Pages.
- При выпуске новой версии: поднять `versionCode`/`versionName` в `android/app/build.gradle`,
  `APP_CODE` в `index.html` и `code`/`name` в `version.json`.

Формат `data.json`:

```json
{
  "updated": "2026-11-15T17:00:00+03:00",
  "days": [
    {
      "date": "2026-11-16",
      "off": false,
      "lessons": [
        { "subject": "Физика", "time": "10:20-11:00", "hw": "Повторить пп. 23" },
        { "subject": "ИЗО", "time": "9:20-10:00", "hw": "", "noHw": true }
      ]
    },
    { "date": "2026-11-21", "off": true, "lessons": [] }
  ]
}
```

`updated` — время последнего изменения (по нему приложение понимает, какая копия свежее).
`hw: ""` — домашки в источнике не было; `noHw: true` — «без домашнего задания».

## Источники данных

Приложение пробует несколько адресов и берёт самый свежий ответ:

1. `data.json` рядом с приложением (GitHub Pages или встроенная копия в APK);
2. `https://cdn.jsdelivr.net/gh/Hokch1k/dnevnik@main/data.json`;
3. `https://raw.githubusercontent.com/Hokch1k/dnevnik/main/data.json`;
4. `https://Hokch1k.github.io/dnevnik/data.json`.

Свой адрес можно задать в приложении: кнопка «i» → «Свой адрес данных».

## Чат класса

Кнопка с облачком в шапке. Первый вход — по коду класса (код выдаёт староста, в репозитории
его нет, поэтому чужой человек с APK чат не откроет).

- Сообщения шифруются на телефоне: AES-GCM, ключ выводится из кода класса через PBKDF2
  (120 000 итераций). Сервер получает только шифротекст.
- Тема на сервере тоже выводится из кода класса (SHA-256), так что без кода её не найти.
- Транспорт — публичный бесплатный сервис ntfy.sh: без аккаунтов и ключей. Сервер хранит
  сообщения 12 часов, приложение кэширует их у себя.
- Без интернета видно последние загруженные сообщения; написанные офлайн уходят, когда сеть
  возвращается.
- Имя для чата задаётся один раз (кнопка «i» → «Имя в чате»).
- Закрыть чат — крестик в шапке чата (или кнопка «назад» на телефоне, или свайп вниз).
- Своё сообщение: правая кнопка мыши (на телефоне — долгое нажатие) → «Изменить» или «Удалить».
  Меню появляется рядом с сообщением, текст правится прямо в ленте. Админ может править и
  удалять чужие сообщения и фото; обычный участник — только свои.
- Выделять текст в чате нельзя: меню вызывается только правой кнопкой или долгим нажатием,
  браузерное меню на сообщениях отключено.
- Фото и видео — кнопка со скрепкой в строке ввода. Картинки сжимаются на телефоне (до 1200 px,
  JPEG) и уходят вложением в ntfy, лимит 12 МБ на файл. Видео — как есть, без сжатия.
  Перед отправкой показывается предпросмотр с кнопками «Отправить» и «Отмена».
- На компьютере картинку можно просто вставить из буфера: Ctrl+V в поле сообщения.
- Картинка в ленте открывается по нажатию в увеличенном виде (лайтбокс), а не скачивается.
- Важно: шифруется **текст сообщения**, а сам файл ntfy хранит открыто (ссылка со случайным
  именем). Файлы на ntfy живут около 12 часов, дальше они остаются только в кэше телефонов,
  которые их уже скачали.

Смена кода класса = смена ключа и темы: старые сообщения перестанут читаться. Для этого
нужно пересчитать `CHAT_SALT_V`, `CHAT_CHECK`, `CHAT_TOPIC_SALT` в `index.html`.

## Расписание на будущие дни

В `data.json` есть `template` — недельный шаблон (ПН–ПТ). Приложение показывает его для любой
даты, которой нет в `days`, поэтому расписание есть всегда; суббота и воскресенье — выходные.

## Админ-панель

Кнопка «i» → «Админ». Вход по отдельному коду администратора (в репозитории его нет).
Внутри: «Пользователи», «Очистить чат» (удаляет сообщения у всех) и «Выйти из админки».

Расписание и ДЗ правятся прямо на экране дня (только у того, кто ввёл код):

- карандаш у предмета — изменить урок, в том числе **номер урока** (1, 2, 3…): урок
  вставляется на выбранное место;
- карандаш справа в строке — домашнее задание (есть переключатель «Без домашнего задания»);
- скрепка — ГДЗ: текст с решением или картинка/файл, видно всем ученикам под домашкой;
- крестик — удалить урок;
- «+ Добавить урок» снизу списка.

Добавление, удаление и правка предметов/времени меняют расписание **для всех недель** этого дня
недели: обновляется `template`, он сохраняется в `localStorage` (`tmpl_ov`) и публикуется всем
через ntfy. Домашка при этом остаётся на конкретную дату, а не переезжает на следующие недели.

Правки дня хранятся в `localStorage` (`sched_ov`) и подтягиваются всеми клиентами через ntfy;
`data.json` на GitHub при этом не меняется.

## Уведомления

«i» → «Уведомления»: отдельно про домашку и про чат.

- В APK используются системные уведомления Android (мост `DnevnikNative`), разрешение
  спрашивается при первом запуске.
- В APK работает фоновая служба `NotifyService`: пока приложение закрыто, она раз в 5 минут
  проверяет чат класса (расшифровывая сообщения ключом из постоянного хранилища), `data.json` и
  опубликованные правки расписания, а скачанное складывает в предзагрузку — при открытии
  приложение сразу показывает свежую домашку и чат. Служба перезапускается после перезагрузки
  телефона и обновления приложения (`BootReceiver`), а свайп из списка задач её не останавливает.
  В системе висит незаметное уведомление «Дневник следит за домашкой и чатом» — это требование
  Android к фоновым службам.
- Если телефон aggressively «усыпляет» приложения, в «i» → «Уведомления» есть кнопка
  «Разрешить работу в фоне» (отключает оптимизацию батареи для Дневника).
- В браузере — обычный `Notification` API (на iPhone работает только при установке PWA), и
  уведомления приходят, только пока вкладка открыта.
- Постоянное хранилище APK дублируется в `SharedPreferences` через мост `loadState/saveState`,
  а локальный сервер занимает постоянный порт, поэтому код чата, имя и настройки не слетают
  после перезапуска.

## Ограничение транспорта

ntfy.sh бесплатный и без аккаунтов, но режет запросы с одного IP (60/час). Чат поэтому
работает на WebSocket-подписке (одно соединение, мгновенная доставка), опрос — только
запасной путь. Если сеть общая (школьный Wi-Fi) и лимит исчерпан, в шапке чата появится
«сервер ограничил запросы · подождём».

## Локальный запуск

```powershell
node tools/dev-server.js               # http://127.0.0.1:8123
node tools/check.js                    # вёрстка + офлайн (нужен Chrome)
node tools/chat-check.js "код"         # вход, отправка, шифрование на сервере
node tools/ws-check.js "код"           # живая доставка, правка/удаление сообщений
node tools/admin-check.js "код" "код2" # админка: правка урока/ДЗ в дне, шаблон, очистка чата
node tools/attach-check.js "код"       # фото в чате: отправка вложением и приём
node tools/chat-ui-check.js "код"      # предпросмотр, меню ПКМ/долгое нажатие, правка в ленте
node tools/presence-check.js "код"     # список пользователей
node tools/topic-check.js "код"        # тема чата совпадает, история пуста (без отправки)
```

## Сборка APK

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
$env:ANDROID_HOME='C:\Android\Sdk'
cd android
gradle assembleRelease
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`.
Ключ подписи лежит в `keystore/` (в git не попадает — приложение обновляется поверх старой
версии только с тем же ключом).

Вёрстка для телефона: `applicationId ru.dnevnik.app`, minSdk 24 (Android 7+).
